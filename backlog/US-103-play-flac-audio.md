# US-103 — Play FLAC audio

**Status:** 📋 Ready (filed 2026-11-07 from the media-format survey) · **Epic:** Media formats ·
**Blocked by:** US-100 (playback of media decoded in Java) · **Blocks:** none

## Story
As a JavaFX application developer,
I want `.flac` files to play through `Media`, `MediaPlayer` and `AudioClip` on every desktop OS,
so that an application plays lossless audio as it is, without converting it first.

## Problem
`impl/` is `modules/javafx.media/src/main/java/com/sun/media/jfxmediaimpl/`, `scene/` is
`modules/javafx.media/src/main/java/javafx/scene/media/` and `native/` is `modules/javafx.media/src/main/native/`.
- **Not recognised.** The extension map has no `.flac` (`impl/MediaUtils.java:190-227`), so the file's bytes decide.
  `fLaC` matches no signature and the check throws "Unrecognized file signature!" (`impl/MediaUtils.java:179`), which
  `Media` and `AudioClip` report as `MEDIA_UNSUPPORTED` (`scene/Media.java:409-410`, `scene/AudioClip.java:90-91`).
- **No decoder.** gstreamer-lite registers no FLAC element
  (`native/gstreamer/gstreamer-lite/projects/plugins/gstplugins-lite.c:34-67`). Its only audio parsers are MPEG audio
  everywhere and AAC on Linux (`modules/javafx.media/native/linux.cmake:314-316`, `mac.cmake:533-534`,
  `win.cmake:635-636`). The Java platform plays nothing (`impl/platform/java/JavaPlatform.java:68-76`).
- **Exactness is checkable.** RFC 9639 (https://www.rfc-editor.org/rfc/rfc9639) puts an MD5 of the unencoded audio in
  STREAMINFO, where 0 means unknown, and a 36-bit total sample count where 0 also means unknown (§8.2). It allows 4 to
  32 bits per sample and 1 to 8 channels (§8.2), with a defined order for 3 to 8 channels (§9.1.3); blocks of 16 to
  65,535 samples (§4.1); constant, verbatim, fixed and LPC subframes (§9.2.1); Rice-coded residuals with 4- or 5-bit
  parameters and escapes (§9.2.7); seek table, Vorbis comment and picture blocks (§8.5, §8.6, §8.8); and a mapping
  into Ogg (§10.1).
- **Stereo out today.** On macOS and Linux the native chain passes through a balance element that takes 1 or 2
  channels and outputs 2 (`native/gstreamer/gstreamer-lite/gst-plugins-good/gst/audiofx/audiopanorama.c:87-101`,
  `native/jfxmedia/platform/gstreamer/GstPipelineFactory.cpp:953-958`).
- **Documentation.** The public container table has no FLAC row (`scene/package-info.java:83-109`), and the metadata
  table documents MP3 tags only (`scene/package-info.java:189-207`).
- **WebView.** WebView hands WebKit `MediaManager.getSupportedContentTypes()`
  (`modules/javafx.web/src/main/java/com/sun/javafx/webkit/prism/PrismGraphicsManager.java:155`), and WebKit answers
  `canPlayType` from the container type alone
  (`modules/javafx.web/src/main/native/Source/WebCore/platform/graphics/java/MediaPlayerPrivateJava.cpp:225-228`). A
  new type therefore changes WebView's answers with no javafx.web change.

## Out of scope
- FLAC in Matroska or MP4, and writing FLAC.
- Playing FLAC when the media natives fail to load (US-100 leaves that out of scope).

## Acceptance criteria
1. **Plays everywhere.** `.flac` files play through `Media`, `MediaPlayer` and `AudioClip` on Windows, macOS and
   Linux, recognised by name (any case), by an HTTP `audio/flac` header and by their bytes. Playback keeps the
   `MediaPlayer` contract of the formats that play today: status transitions and events, seek, rate, cycle count,
   start and stop time, markers, volume, balance, mute, equalizer and audio spectrum.
2. **Exact output.** Decoded PCM matches the STREAMINFO MD5 for every file of a corpus covering every bit depth from 4
   to 32, 1 to 8 channels, sample rates up to 192 kHz (8, 44.1, 48, 96 and 192 kHz, and a rate given only in
   STREAMINFO), fixed and variable block sizes from 16 to 65,535 samples with a short last block, every subframe type
   and predictor order, wasted bits, every stereo decorrelation, both Rice parameter widths, escaped partitions and
   every partition order. Decoded PCM is identical on the five CI targets.
3. **Channels.** How 1 to 8 channels reach the output, including the coefficients of each downmix to fewer channels,
   is documented in the public format table and checked by tests.
4. **Sample-accurate seek.** After `seek(t)` the first sample played is sample ⌊t × rate⌋, with and without a seek
   table, and the same holds where playback restarts at a start time or a cycle repeat. When STREAMINFO's total sample
   count is non-zero, `Media.getDuration()` is that count divided by the sample rate. A zero count means the length is
   unknown, not empty (RFC 9639 §8.2). The duration is then the number of samples the stream holds divided by the sample
   rate: for a `file:`, `jar:`, `jrt:` or `resource:` source, or an HTTP source whose server honours range requests, it
   is known before the player reaches `READY`; for any other source `Media.durationProperty()` is `Duration.UNKNOWN`
   until the end of the stream is reached and then changes to that value. While the duration is unknown, a seek past the
   last sample ends playback at the last whole frame, as criterion 6 does for a truncated end. A stream with a zero
   count and no audio frames reports `Duration.ZERO`. A test on a corpus file whose count a recorded command zeroes
   asserts the duration before `READY` for a `file:` source, the `UNKNOWN`-then-exact sequence for a streamed source,
   and never zero.
5. **Metadata.** Vorbis comments reach `Media.getMetadata()` under the keys the public metadata table documents
   (title, artist, album, album artist, composer, genre, year, track and disc number and count, comments), and the
   front-cover picture reaches `image`. The mapping is documented in that table.
6. **Damaged input.** A file whose STREAMINFO is missing or damaged fails with US-096's error naming the cause. A
   frame whose CRC fails, or a truncated end, is skipped or ends playback at the last whole frame; it is logged and
   never hangs, crashes or plays noise. A seeded mutation run over the corpus, with its seed and count recorded, meets
   the same rule.
7. **FLAC in Ogg.** FLAC in Ogg (RFC 9639 §10.1) plays and meets criteria 2 to 6 once US-104's Ogg demuxing exists.
8. **Documented and visible.** The public container and encoding tables list FLAC. WebView's
   `canPlayType("audio/flac")` answer changes from empty to "maybe"; the change is checked and recorded.
9. **Nothing else changes.** The media module's tests pass with the counts of a run before the change, plus the new
   tests. No public API is added. All five CI legs are green.
